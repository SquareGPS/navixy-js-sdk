Deprecated

The Navixy JavaScript SDK is no longer maintained

This SDK has been retired. For building integrations with the Navixy platform, use the actively maintained REST API and our machine-readable OpenAPI specifications.

The API is language-agnostic and codegen-friendly, so you can generate a typed client in the language of your choice.

Navixy Developer Hub OpenAPI specs on GitHub

The source repository is archived for reference at github.com/SquareGPS/navixy-js-sdk.
